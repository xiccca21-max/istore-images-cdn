# iStore Images CDN

Public image repository for iStore storefront assets.

## Folder structure

- `hero/` - homepage hero banners
- `categories/` - category images
- `products/` - product model images
- `variants/` - variant-specific images

## Recommended naming

- Use lowercase latin letters, numbers, `-` and `_`
- Avoid spaces and Cyrillic symbols in file names
- Prefer `.webp` for product and hero images
